# Froshella 2026: GDG table at Newnham

There are no slides for this event. It is a club table at the SSF Froshella fair, not a talk.

What visitors see at the table instead:

- **GDG Bug Jump**, a browser game where you jump in front of the camera to make the dino jump over bugs. Dodging 5 bugs earns a spin of the prize wheel, followed by a QR code to join the chapter. Play it at [gdg-bug-jump.vercel.app](https://gdg-bug-jump.vercel.app). The source code is in [bug-jump/](bug-jump/) if you want to run or remix it.
- Printed photos from past events.
- A printed timeline of upcoming events: the Info Session on 23 September, then a code jam and a hackathon.

## Pitch

We're Google Developer Group @ Seneca. We're not only about Google. We're a student community for anyone into tech who wants to build things. You work on real projects with a team, learn Google tools, and get better at presenting and networking.
